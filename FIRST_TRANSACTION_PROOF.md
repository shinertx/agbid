# AgBid First Transaction Proof

## Objective

Prove or kill AgBid with one real farmer buying request and three blind delivered supplier bids.

## Development Type

AgBid is being built as a transaction-first concierge MVP.

That means the first product is not a full app. The first product is a managed buying desk:

1. Farmer gives one real request.
2. Operator recruits three suppliers.
3. Suppliers submit blind delivered bids.
4. Farmer picks a bid if it beats the hidden target.
5. AgBid manually reviews label, freight, payment, and Texas compliance before money moves.

Only repeated manual steps get automated.

## Public Farmer Rule

The farmer should see one link or one text prompt.

Do not send farmers the operator board, supplier onboarding, supplier bid link, pilot leads, deal desk, or label review pages. Those are internal tools.

## Farmer Ask

Nathan Burson moved to the supply side (cofounder, Wilbur-Ellis) on 2026-08-20, so the pilot grower slot is open. Send this to the first real grower candidate:

```text
For the AgBid test, I only need one real buying request:

1. Product or brand
2. Gallons
3. Delivery ZIP
4. Need-by date
5. Delivered price where you would lock it in

If suppliers beat that delivered price, would you be willing to pick the bid through AgBid?
```

## Proof Standard

The farmer lead is real only if he provides:

- Product or brand
- Gallons
- Delivery ZIP
- Need-by date
- Hidden target price
- Yes/no on must-pick if the target is beaten

The pilot is real only if AgBid then gets:

- Three Texas-capable suppliers
- Blind delivered bids with freight included
- EPA registration number on each bid
- Supplier acceptance of AgBid as clearing party

## Kill Standard

Kill or pivot the current marketplace thesis if:

- Farmers will not give a hidden target price.
- Farmers will not agree to pick a bid that beats the target.
- Suppliers will not submit blind delivered bids.
- Suppliers will not let AgBid clear the transaction.
- Freight erases the savings.
